# 打鍵リーダー

小説を読みながら、**かな入力＋漢字変換**を練習するための特殊テキストエディタ。

ローマ字入力の速度を測るタイピングゲームは多いが、日本語入力の実際の負荷は
「変換をどこで区切るか」「誤変換をどう直すか」にある。このツールはそこを練習対象にする。

- 変換の区切りはユーザーの自由（入力すべき文字数が可変長）
- 誤入力しても止まらない。編集距離で現在位置を求めるため自己回復する
- 打った文字は消えずに残り、スクロールで見返せる
- 画面下端を横に流れる「お手本テープ」が原稿用紙のマス目で先を示す
- 本文は青空文庫から実行時に取得する

## 使い方

`index.html` を開くだけ。ビルド不要・依存なしの単一 HTML。

GitHub Pages に置く場合は Settings → Pages で `main` ブランチのルートを指定する
（`.github/workflows/pages.yml` を使う場合は Source を GitHub Actions にする）。

### 作品の読み込み

「作品」ボタンから3つの経路がある。

1. **プリセット** — 収録作品を選ぶ（カードIDは未検証のものを含む）
2. **カードURL** — 青空文庫のカードページURLを貼る（確実な経路）
3. **直接貼り付け** — 青空文庫記法のまま貼れる。通信が使えない環境の最終手段

青空文庫本体リポジトリを `raw.githubusercontent.com` 経由で取得する。
カードページを解析して本文XHTMLのリンクを得る2段構え
（作品IDから本文ファイル名を導出できないため）。

## 統計の読み方

| 指標 | 目安 |
|---|---|
| 打鍵効率（打/字） | かな入力 1.3〜1.8 / ローマ字入力 2.2〜 |
| 平均変換長（字/変換） | 5〜10字。長すぎると誤変換時のやり直しが重い |

ブラウザからは入力方式（かな／ローマ字）を判別できないため、
打鍵効率が「かな入力できているか」の唯一の指標になる。

## 開発

```sh
node --test "test/*.test.mjs"
```

`index.html` は単一ファイルを維持している（アーティファクト等でそのまま動かせるため）。
テストは `//#region testable` 〜 `//#endregion testable` の範囲を抜き出して実行する。
この領域には DOM に依存しない純粋なロジック（記法パーサ・判定エンジン・描画用純粋関数）だけを置くこと。

`test/invariants.test.mjs` は、実機バグから導出した「守らないと壊れる」規則を
コード上で機械的に検査する。IME 周りの落とし穴は再発しやすいため、
これらを緩めるときは `docs/仕様書.md` の該当箇所を必ず読むこと。
