# お手本テープの描画

[仕様書.md](仕様書.md) の各論。テープの余白・字送り・位置合わせ・仮想化を扱う。
「守らないと壊れる」規則の多くは `test/invariants.test.mjs` が機械的に検査する。

## 余白と高さ

テープは画面下端に貼り付けず、上下を同じ罫線で閉じて下端から浮かせる。原稿用紙から切り出した一片として見せるため。

**高さは固定値で持たず、下から積み上げて導出する。**

```
┌──────────────── 上罫線
│  --tapePadB     余白（下と同じ）… ルビはこの中へはみ出す
│  --fs           文字
│  --tapePadB     余白
└──────────────── 下罫線
   --tapeGapB     外側の余白
   safe-area
```

- **縦位置は文字だけで決め、ルビは数えない。** ルビは全文字に付くものではないので、ルビぶんの高さを積むとルビのない行では文字が下に寄って見える。ルビは上側の余白（`--tapePadB`）へはみ出させる。したがって `--tapePadB` はルビの高さを下回れない（下回ると `overflow:hidden` で頭が切れる）。
- `--tapeH` は導出値なので**メディアクエリで上書きしない**。画面幅ごとに指定してよいのは `--fs` / `--tapePadB` / `--tapeGapB` の3つだけ。
- 入力欄（`.stage`）の下端は、テープの占有高の合計 `--tapeBand` だけを参照する。個別の値を足すと、余白を変えたとき入力欄がテープに潜り込む。
- 朱のマーカーも文字を中心に上下対称に置き、はみ出し量は `--fs` に比例させる（rem 固定だと `--fs` を下げたとき相対的に長くなりすぎる）。

## 字送りの一致

入力欄とテープは行内の字送りが1文字単位で一致していなければ、テープが文字ごとに揺れる。条件は次のとおり。

- **同じフォント・同じフォントサイズ・letter-spacing は両方 normal。**
- **英数字は全角幅に揃えず、可変幅のまま描く。** 全角に引き伸ばした英文は違和感が強い。同じフォント・同じサイズなら可変幅でも一致する。1マス固定にしてよいのは、入力欄に対応する文字を持たない改行記号 `¶` だけ。
- **カーニングとリガチャは両方で切る。** テープは1セル＝1文字の inline-block なのでペアカーニングが効かず、入力欄だけ `AV` / `To` が詰まるとその差ぶんテープが流れる。
- **半角スペースは `word-spacing` で全角の半分に広げ**、テープ上で空のマスとして判別できるようにする。入力欄・テープ・実測用プローブ（`.probe`）の3箇所すべてに同じ値を掛ける。
- **半角スペースを潰さない。** 入力欄は `pre-wrap`、セルは `pre`。潰れると `caretX` が進まず、セル幅が 0 になる。

## 位置合わせ

フォント幅を一切仮定せず、実測座標から毎回算出する。

```js
tx   = caretX - leftInTape(cell[cursor])              // 原則: キャレットに揃える
over = (caretX + 先読み LOOKAHEAD 字の幅) - (テープ幅 - 余白)
if (over > 0) tx -= over                              // 先読み確保のため押し戻す
markerX = tx + leftInTape(cell[cursor])
```

- `caretX` … `live` 内のアンカー要素の X 座標（テープ表示域の左端が原点）
- `leftInTape()` … `offsetParent` を辿って `.tape` 基準の左端を求める。`transform` の影響を受けない

行の途中ではキャレットとセルが同じ幅ずつ進むため差分ゼロ＝**テープ静止**。折り返しでキャレットが左端へ戻った瞬間に1行ぶん**スライド**する（`transition: transform 180ms`）。

押し戻しが効いている間は `caretX` とともに `over` も増えるため、現在位置のセルが右端付近に固定されたままテープだけが流れる、タイプライタ的な挙動になる。折り返しで `over` が負に転じ、通常のキャレット追従へ戻る。朱のマーカーはテープ上のセルに付くので、押し戻し中はキャレットと離れる。

## 仮想化

長編でも DOM 量を一定に保つ。

```html
<div class="tape">
  <i class="sp" style="width:4820px"></i>   <!-- 左スペーサ -->
  <span class="cell">吾</span> …            <!-- 窓（cursor 前後400トークン） -->
  <i class="sp" style="width:9000px"></i>   <!-- 右スペーサ -->
</div>
```

- **左スペーサが要。** 窓の開始位置ぶんを実際に押し出しておくことで、`offsetLeft` が常に「テープ全体の先頭からの距離」を返す。窓を差し替えてもスペーサ幅が同じだけ増減するため描画中セルの `offsetLeft` は不変で、**飛びが原理的に発生しない**。
- 再構築は cursor が窓端から150トークン以内に入ったとき（ヒステリシス）、`requestAnimationFrame` 内で translateX 更新より先に行う。
- スペーサ幅は実測済みセル幅の累積和＋未描画部分の推定値（`estW`）。推定の誤差は `tx` の式の両辺に同じだけ乗って打ち消されるため、画面上の位置合わせには影響しない（ずれるのはテープの総延長だけ）。
- 半角スペースと `¶` の幅は実測する。フォント依存の値を決め打ちしない。
